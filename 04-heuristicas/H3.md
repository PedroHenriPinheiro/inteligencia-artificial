# 3º Heurística - João Victor + Gemini (Expansão da Segunda Heurística)

## Heurística: utilizar abordagens baseadas em bloqueios ao invés da distância espacial no tabuleiro

A nova hipótese tem como base a seguinte regra: Uma ação movimenta exatamente um veículo. Se o veículo A e B estão bloqueando X, nenhuma ação única no jogo inteiro é capaz de mover A e B ao mesmo tempo.

Portanto, é garantir que é necessário pelo menos uma ação isolada para mover A e outra para mover B.

## Níveis de Bloqueio

Para transformar as regras teóricas abordadas na `Heurística 2` em uma função admissível, os bloqueios do tabuleiro são divididos em níveis estritos de dependência:

`Nível 0: O Veículo Principal (X)`

- Fato inevitável: X precisa mover-se para a direita, rumo à saida
- Dependência: Atrapalhado pelo `Nível 1`
- Custo mínimo: Se o caminho estiver livre, o custo `c` é exatamente 1

`Nível 1: Bloqueadores Diretos`

- Definição: Qualquer veículo fisicamente posicionado entre a frente de X e a porta de saída, `veículos Verticais`
- Fato inevitável: Para liberar o caminho de X, esses veículos verticais precisam se mover para `Cima/Baixo`
- Dependência: Atrapalhado pelo `Nível 2`
- Custo mínimo: Cada bloqueador direito exige pelo menos 1 ação


`Nível 2: Dependências e Alternativas Legais`

- Definição: `Veículos (Horizontais)` bloqueando a rota de fuga (Cima/Baixa) dos veículos de Nível 1
- Fato inevitável: Para que o Nível 1 se mova, o Nível 2 precisa mover-se para a `Esquerda/Direita`
- Dependência: Atrapalhados pelo `Nível 3`

`Nível 3 em diante: Efeito Cascata`

A cadeia segua alternando as orientações. O Nível 3 (Verticais) impedem os veículos do Nível 2 de irem para os lados. O Nível 4 (Horizontais) impedem o Nível 3 de ir para Cima/Baixo, e assim por diante

## Formalização Matemática

A mecânica de bloqueios se traduz na seguinte função para qualquer estado n: `h(n) = C + |D(n)|`

Onde:
- `C` = 1 se o veículo X ainda está no tabuleiro (custo obrigatório de saída), 0 caso contrário
- `D(n)` = O Conjunto de Dependências Garantidas. Um set que mapeia o identificador único de todos os veículos que obrigatoriamente precisarão se mover, independentemente da profunidade da cadeira. O tamanho desse cojunto define o custo acumulado de ações estruturais inevitáveis.

`Cálculo do Conjunto de Dependências D(n)`

Para mapear a cadeira de bloqueios sem superestimar o custo, o agente avalia recursivamennte as rotas de fuga para cada veículo encontrado no caminho:

1. `Deslocamento Real`: Uma rota só é considerada viável se houver células livres suficientes `(células_livres >= deslocamento_necessario)` para que o veículo desobstrua completamente o espaço do elemento anterior.

2. `Limites Absolutos`: Se a direção de fuga apontar para a borda do tabuleiro (linha 0 ou 11) antes de atingir o deslocamento necessário, aquela rota é descartada como inválida.

3. `Minimização e Prevenção de Loops`: O agente repassa um histórico de veículos visitados `(visited)`. Se uma ramificação reencontrar um veículo já presente no histórico, um ciclo fechado é detectado, invalidando o ramo `(retorna C = Infinito)`

4. `Interseção de Rotas em Bifurcação`: Quando um veículo possui múltiplas rotas de fuga válidas, o agente não assume a soma das rotas (o que causa dupla contagem). Em vez disso, ele aplica a interseção entre os ramos viáveis, assumindo como custo obrigatório apenas os veículos que aparecem obrigatoriamente em ambas as opções de fuga.

Formalmene, para qualquer veículo `u`, suas dependências são calculadas como:
`D(u) = {u} U (D(Rota_negativa) ∩ D(Rota_positiva))`

## Garantia de Admissibilidade e Consistência

A fórmula `h(n) = C + |D(n)|` respeita estritamente o limite inferior e a prova de obrigatoriedade, mantendo a condição `h(n) <= h*(n)` para todos os estados válidos.

A garantia matemática contra superestimativas reside na operação de Interseção de Cojuntos. Como o agente explora o Efeito Cascata em profunidade `(Níveis 3, 4,...)`, ele inevitavelmente se depara com bifurcações de escape. Ao utilizar exclusivamente a interseção dos subconjuntos de dependência nas ramificações viáveis, a heurística assegura que nenhum obstáculo alternativo seja contabilizado como inevitável se ele puder ser evitado por uma escolha futura do A*. Dessa forma, `h(n)` permanece como um limite inferior estrito e consistente para todas as transições do tabuleiro.

## Casos Limites e Estado Objetivo

- Caminho Livre: Se o caminho de X está vazio, `D(n) = Ø`. Logo `h(n) = 1`. O agente entende que basta um único movimento para sair do tabuleiro.
- Estado Objetivo: No estado onde X já realizou o movimento de saída, `C = 0` e `D(n) = Ø`, resultando em `h(n) = 0`. A estimativa no objetivo zera, cumprindo a exigência final para a consistência do A*.
