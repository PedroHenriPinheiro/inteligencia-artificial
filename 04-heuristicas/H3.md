# 3º Heurística - João Victor + Gemini (Expansão da Segunda Heurística)

## Heurística: utilizar abordagens baseadas em bloqueios ao invés da distância espacial no tabuleiro

A nova hipótese tem como base a seguinte regra: Uma ação movimenta exatamente um veículo. Se o veículo A e B estão bloqueando X, nenhuma ação única no jogo inteiro é capaz de mover A e B ao mesmo tempo.

Portanto, é garantir que é necessário pelo menos uma ação isolada para mover A e outra para mover B.

## Níveis de Bloqueio

Para transformar as regras teóricas abordadas na `Heurística 2` em uma função admissível, os bloqueios do tabuleiro são divididos em níveis estritos de dependência:

`Nível 0: O Veículo Principal (X)`

- Fato inevitável: X precisa mover-se para a direita, rumo à saida
- Dependência: Atrapalhado pelo `Nível 1`
- Custo mínimo: Se o caminho estiver livre, o custo `c` é exatamente 1

`Nível 1: Bloqueadores Diretos`

- Definição: Qualquer veículo fisicamente posicionado entre a frente de X e a porta de saída, `veículos Verticais`
- Fato inevitável: Para liberar o caminho de X, esses veículos verticais precisam se mover para `Cima/Baixo`
- Dependência: Atrapalhado pelo `Nível 2`
- Custo mínimo: Cada bloqueador direito exige pelo menos 1 ação


`Nível 2: Dependências e Alternativas Legais`

- Definição: `Veículos (Horizontais)` bloqueando a rota de fuga (Cima/Baixa) dos veículos de Nível 1
- Fato inevitável: Para que o Nível 1 se mova, o Nível 2 precisa mover-se para a `Esquerda/Direita`
- Dependência: Atrapalhados pelo `Nível 3`

`Nível 3 em diante: Efeito Cascata`

A cadeia segua alternando as orientações. O Nível 3 (Verticais) impedem os veículos do Nível 2 de irem para os lados. O Nível 4 (Horizontais) impedem o Nível 3 de ir para Cima/Baixo, e assim por diante

## Formalização Matemática

A mecânica de bloqueios se traduz na seguinte função para qualquer estado n: `h(n) = C + B + E`

Onde:
- `C` = 1 se o veículo X ainda está no tabuleiro (custo obrigatório de saída), 0 caso contrário
- `B` = quantidade de veículos bloqueadores diretos (Nível 1) na frente de X
- `E` = Custo adicional de ações inevitáveis no Nível 2. É calculado através do conjunto de rotas de fuga mínimas para evitar dupla contagem.

`Cálculo da Variável E`

Para cada veículo `v` no conjunto de bloqueadores `B`, o agente calcula o custo de fuga determinando o caminho de menor esforço: `Fuga(v) = min(Custo(Cima), Custo(Baixo))`

A funçao `Custo(direção)` aplica estritamente as seguintes validações:

1. `Deslocamento Real`: O custo só é 0 se `células_livres >= deslocamento_necessario` para v desobstruir a linha de X.

2. `Limites Absolutos`: Se a direção apontar para a borda do tabuleiro (ex: linha 0, ou 11) antes de atingir o deslocamento necessário, o custo retorna infinito.

3. `Minimização e Prevenção de Loops`: Se a direção encontrar um veículo de Nível 2 (ou um ciclo/deadlock no histórico de recursão), a direção é vinculada a esse obstáculo.

Após calcular Fuga(v) para todos os bloqueadores em B, a varíavel E é definida como a quantidade veículos únicos de Nível 2 que compõem as rotas de menor esforço escolhidas.

## Garantia de Admissibilidade

A fórmula `h(n) = C + B + E` respeita o limite inferior e a prova de obrigatoriedade, mantendo a condição `h(n) <= h*(n)` para todos os estados válidos. O custo C e o conjunto B contabilizam ações inescapáveis (1 para a saída e 1 para cada bloqueador direto), sustentadas pela impossibilidade física de sobreposição dos veículos.

A garantia contra superestimativas reside na transformação lógica da variável E. Ao aplicar a função `min(Custo(Cima), Custo(Baixo))`, na avaliação de fugas, o agente assume o caminho de menor esforço, evitando contabilizar a remoção de obstáculos em rotas alternativas que nunca serão utilizadas. Finalmente, ao agrupar exclusivamente os veículos únicos de Nível 2 que compõem essas rotas mínimas, a heurística bloqueia a dupla contagem de ações simultâneas, assegurando que, mesmo que um único veículo de Nível 2 libere múltiplos bloqueadores diretos, o custo extra refletido seja de apenas `+1`.

## Casos Limites e Estado Objetivo

- Caminho Livre: Se o caminho de X está vazio, `B = 0` e `E = 0`. Logo `h(n) = 1`. O agente entende que basta um único movimento para sair do tabuleiro.
- Estado Objetivo: No estado onde X já realizou o movimento de saída, `C = 0`, resultando em `h(n) = 0`. A estimativa no objetivo zera, cumprindo a exigência final para a consistência do A*.
